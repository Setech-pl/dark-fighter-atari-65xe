# Music sources

`menu-theme.json` is the editable source for the original menu composition
“Fleet in Shadow”. `npm run build` validates it through
`scripts/menu-music.mjs` and generates `build/menu-music.inc`; generated bytes
must not be edited by hand.

The source stores POKEY frequency dividers, instrument control bytes, fixed
16-row/four-channel patterns, and their order table. Timing is locked to one
row every eight PAL frames at 50 Hz.
